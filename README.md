# Замер скорости интернета

Консольный скрипт на Python: делает несколько последовательных запросов к указанному адресу, дожидается полного ответа на каждый и считает среднее время запроса, общий объём скачанных данных и скорость скачивания.

Внешних зависимостей нет, используется только стандартная библиотека.

## Требования

- Python 3.8+

## Запуск

```bash
python speedtest.py <URL>
```

Пример:

```bash
python speedtest.py https://proof.ovh.net/files/10Mb.dat
```

Если схема не указана, подставляется `https://`.

### Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `url` | — | адрес, к которому стучаться (например, тяжёлая картинка) |
| `-n`, `--count` | `10` | количество запросов |
| `-t`, `--timeout` | `30` | таймаут одного запроса, в секундах |

## Пример вывода

```
URL: https://proof.ovh.net/files/10Mb.dat
Requests: 10

[ 1/10]   10.49 MB    9.771 s
[ 2/10]   10.49 MB    9.356 s
...
[10/10]   10.49 MB    8.695 s

Results
  Successful requests: 10/10
  Average request time: 9.398 s
  Total downloaded:     104.86 MB
  Download speed:       8.93 Mbit/s (1.12 MB/s)
```

## Единицы измерения

- **Время** — секунды (`s`).
- **Объём** — мегабайты (`MB`), десятичные: 1 MB = 1 000 000 байт.
- **Скорость** — мегабиты в секунду (`Mbit/s`), 1 Mbit = 1 000 000 бит. Именно в этих единицах скорость указывают провайдеры. Дополнительно в скобках выводится то же значение в `MB/s`.

## Как считается

- Время запроса — от отправки запроса до получения последнего байта тела ответа. Сюда входят DNS, установка TCP/TLS-соединения и ожидание ответа сервера.
- Среднее время запроса = сумма времени успешных запросов / их количество.
- Скорость = (общий объём в байтах × 8) / суммарное время успешных запросов.
- Запросы идут строго последовательно, следующий начинается только после того, как полностью скачан предыдущий.
- В запрос добавлен заголовок `Cache-Control: no-cache`, чтобы промежуточные кэши по возможности не отдавали ответ из кэша.

## Ошибки

Если запрос не удался (нет сети, HTTP-ошибка, таймаут), ошибка печатается, и скрипт переходит к следующему запросу. Итоги считаются только по успешным.

Код выхода:

- `0` — все запросы успешны;
- `1` — ни один запрос не удался;
- `2` — часть запросов завершилась ошибкой.

Некоторые сайты (например, Wikimedia) могут отвечать `429 Too Many Requests` на запросы из скриптов — в этом случае возьмите другой адрес.
